# موقع الخطوبة 💍 — لـ سارة

## 🚀 إزاي تخليه شغال على النت (٣ خطوات)

1. ارفع كل الملفات دي على الريبو `sarah` على GitHub
2. روح **Settings → Pages**
3. تحت **Source** اختار **Deploy from a branch** → البرانش `main` → الفولدر `/ (root)` → **Save**

استنى دقيقتين والموقع هيبقى شغال على:

```
https://mohamed4aker.github.io/sarah/
```

---

## 📸 صورة سارة

حط الصورة جوه فولدر `images` باسم **`sarah.jpg`** بالظبط:

```
images/sarah.jpg
```

لو الصورة مش موجودة، الموقع هيعرض حرف «س» في دايرة وردي — يعني مش هيبوظ.

---

## 🗓️ تغيير تاريخ العداد

في ملف `script.js` فوق خالص:

```js
const CONFIG = {
  startDate: new Date(2024, 0, 1, 0, 0, 0), // (سنة، شهر-1، يوم)
};
```

⚠️ الشهر بيبدأ من **0** — يناير = `0`، فبراير = `1`، ديسمبر = `11`.

## 💻 تجربته على جهازك

افتح `index.html` على طول في المتصفح، أو:

```bash
python3 -m http.server 8000
# وبعدين افتح http://localhost:8000
```
