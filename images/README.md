# فولدر الصور

حط صورة سارة هنا باسم **`sarah.jpg`** بالظبط.

المسار المطلوب:

```
images/sarah.jpg
```

نصايح:
- يفضّل صورة مربعة (مثلاً 800×800) عشان تظهر أحلى في الإطار الدائري.
- لو الصورة مش مربعة، الموقع هيقصّها تلقائيًا من النص (`object-fit: cover`).
- لو مفيش صورة، هيظهر حرف «س» في دايرة وردي بدل ما الصفحة تبوظ.
